# Hi, I'm Marc 👋

I'm a long-time developer in the media industry, now focused on **how AI can support decision-making and knowledge work**. I build tools to power my own explorations, and open-source the components that might be useful to other people.

I'm building [Lyra Forge](https://lyra-forge.com), a media-oriented product factory, and exploring how cutting-edge tools can make new forms and formats possible. Current active, public-facing experiments:

* NJ School Data - https://njschooldata.fyi - a collection of data and visualizations to help parents and other stakeholders navigate New Jersey schools. Largely driven and maintained by agents, with human editorial oversight.
* Backfield - https://backfield.net - An agentic news organization covering the AI & Media beat. Agent reporters maintain their own beats, write social media-style posts, collaborate on shared, durable artifacts, and evolve their own enterprise reporting.


The vast majority of the code here is generated by AI. A lot of it is alpha quality. I'm making it available because it might work for your use case, or it might spark an idea for your tooling/agent to implement on your own.


## Tools for research and data

| Project | What it is |
|---|---|
| **flip** · [docs](https://lavallee.github.io/flip/) · [repo](https://github.com/lavallee/flip) · [examples](https://github.com/lavallee/flip-examples) | **Reporter's notebooks** — research that humans and agents maintain *in the same files*. | **yoinker** · [docs](https://lavallee.github.io/yoinker/) · [repo](https://github.com/lavallee/yoinker) | **Adoption research** — follows an unfamiliar tool or idea back to its sources, checks how it works against your situation, and decides what to borrow, try, track or reject. |

## Tools for working with models and agents

| Project | What it is |
|---|---|
| **somm** · [docs](https://lavallee.github.io/somm/) · [repo](https://github.com/lavallee/somm) | **Self-hosted LLM telemetry and routing** — records your codebase's model calls locally, juggles providers, and learns which models fit which workloads so you're not overpaying. |
| **milton** · [docs](https://lavallee.github.io/milton/) · [repo](https://github.com/lavallee/milton) | **Agent-work intelligence** — reads agent transcripts, run receipts and Git activity to account for cost per outcome and surface recurring failures. |
| **gipper** · [docs](https://lavallee.github.io/gipper/) · [repo](https://github.com/lavallee/gipper) | **GPU jobs across cloud markets** — describe a job in TOML, compare whole-run costs on Runpod and Vast.ai, run it, collect results and verify teardown. |
| **spindle** · [docs](https://lavallee.github.io/spindle/) · [repo](https://github.com/lavallee/spindle) | **Blend skills** — picks the right skills for a repo, lints the blend for coherence, and installs it where each agent harness loads it. |
| **chip** · [docs](https://lavallee.github.io/chip/) · [repo](https://github.com/lavallee/chip) | **Portable operational components** — versioned units that observe declared signals, apply bounded judgment, and keep receipts. Chips compose into circuits that hosts run. |
